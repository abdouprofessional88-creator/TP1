# php-backend — Module 205 : Développement Backend

Cahier d'exercices pratiques PHP (Séquence 01 : Découvrir les framework et CMS PHP).
OFPPT — ISTA Bab Tizimi, Meknès — DEVOWFS.

## Structure

| Dossier | Thème | Exécution |
|---|---|---|
| `activite1-fonctions/` | Fonctions et calculs | `php activite1-fonctions/test.php` |
| `exercice2-tableaux-indexes/` | Tableaux indexés | `php exercice2-tableaux-indexes/tableaux.php` |
| `exercice3-tableaux-associatifs/` | Tableaux associatifs | `php exercice3-tableaux-associatifs/associatifs.php` |
| `exercice4-classes/` | Classes simples (CompteBancaire) | `php exercice4-classes/test.php` |
| `exercice5-heritage/` | Héritage et polymorphisme | `php exercice5-heritage/index.php` |

## Prérequis

PHP 8.1 ou plus (`php -v`). Vérifier la syntaxe d'un fichier : `php -l fichier.php`.

## Règles de qualité

`declare(strict_types=1);`, typage systématique, camelCase / PascalCase, PSR-12.
